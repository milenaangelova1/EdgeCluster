# EdgeCluster
This is the code repository that was developed for the paper "EdgeCluster: An Evolving Data Stream Clustering at the Edge".

# Requirements
The Python version is Python 3.9.
```bash
pip install -r requirements.txt
```


# EDAs
Original synthetic data and Ampds 2 were taken from https://github.com/christiannordahl/EvolveCluster.
Original KDDCup'99 data => https://kdd.ics.uci.edu/databases/kddcup99/kddcup99.html \

All EDAs are in the folder ```notebooks```.

# Cloud based results

All results can be seen visually in the notebooks that are in the root directory.
